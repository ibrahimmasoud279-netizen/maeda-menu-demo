# نموذج صفحة منيو أكل بيتي
نموذج تجريبي مستقل لعرض المهارة، وليس عملًا لعميل أو مطعم حقيقي. لا طلب أو دفع أو إرسال رسائل.

## التشغيل
افتح index.html مباشرة في المتصفح، أو ارفع كل الملفات بنفس ترتيبها على استضافة ملفات ثابتة. لا React أو خدمات خارجية أو تثبيت حزم مطلوبة.

## تعديل الأصناف
افتح menu-data.js. كل صنف له id فريد، name، category، price (رقم بالجنيه المصري)، description، image (اسم الصورة دون الامتداد)، tag اختياري. لتغيير الصورة ضع JPG في assets واكتب اسمها في image. الأقسام تُستخرج من بيانات الأصناف تلقائيًا. لا تدخل بيانات حساسة. استخدم صورًا مسموحًا بها فقط.

## حدود التسليم
التعديل هنا من ملف البيانات، وليس لوحة إدارة آمنة. إذا أراد العميل تعديلًا من لوحة دون تحرير الملفات، فذلك نطاق إضافي يحتاج تحديد وتكلفة وصلاحيات وتخزين. الصور الأربعة مولدة للتوضيح وليست صور مطعم حقيقي. الأسعار والأسماء تجريبية. لا توصيل أو سلة أو دفع أو واتساب أو تحليلات. لا استضافة أو نطاق مدفوع مشمول.

## ما ينقص العميل
الاسم والشعار، المنيو والأسعار والعملة، صور أصناف مرخصة، بيانات الحساسية المراجعة، وأسلوب التعديل المطلوب والاستضافة. لا تفترض أن ميزانية إعلان المشروع اتفاق سعر أو قبول عرض.
